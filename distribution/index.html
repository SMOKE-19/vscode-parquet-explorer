VSIX 다운로드

다운로드 후 VS Code에서 직접 설치하세요.

01

첫 실행 환경 설정

기존 Python을 선택하거나 버튼으로 Python 3.13·DuckDB 전용 환경을 준비합니다.

02

대용량 조회 제어

전체 행 수 계산을 선택하고 조회 취소, 작업자 재시작과 자원 제한을 사용합니다.

03

설치 후 바로 조회

설치 진행 상태와 로그를 확인하고, 완료되면 원래 Parquet으로 돌아갑니다.

설치는 세 단계면 됩니다.

기존 버전을 사용 중이어도
새 VSIX 파일로 다시 설치할 수 있습니다.

  1. 1
    위 버튼으로 VSIX 파일을 다운로드합니다.Tailnet에 연결된 PC에서 다운로드하세요.
  2. 2
    VS Code에서 Ctrl+Shift+P를 누릅니다.Extensions: Install from VSIX...를 선택하고 다운로드한 파일을 엽니다. 재시작 안내가 표시되면 따르세요.
  3. 3
    Parquet 파일을 열고 조회를 시작합니다.환경 설정이 표시되면 기존 Python을 선택하거나 설치를 시작하세요. 전용 환경 설치에는 uv가 필요하며, 없으면 설치 안내가 표시됩니다.

WSL·Remote SSH로 작업한다면 해당 환경에 확장을 설치하세요. Python과 DuckDB도 확장이 실행되는 환경에서 사용합니다. 이 패키지는 Linux의 설치·조회 흐름을 검증했으며, Windows VS Code에서의 직접 검증은 아직 진행하지 않았습니다.
