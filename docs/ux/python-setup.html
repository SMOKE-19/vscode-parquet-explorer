UX 설계 · 구현 반영
사용자가 설치를 시작환경 확인 후 설정 화면을 안내합니다. 설치는 ‘설치 시작’을 눌렀을 때 실행합니다.
실제 실행 환경에 설치Windows · WSL · Remote SSH를 구분해 표시합니다. 기본 위치는 확장 전용 저장소의 .venv를 권장합니다.
성공하면 원래 파일로 복귀Python 3.13과 DuckDB를 준비·검증한 뒤 Parquet을 자동 조회합니다. 이후에는 환경을 재사용합니다.
